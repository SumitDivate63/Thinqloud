# Security and Authentication Architecture

## Authentication Model
- **Primary Authentication**: Firebase Auth with Google OAuth (`GoogleAuthProvider`).
- **Identity Tokens**: JWT tokens generated by Firebase Auth passed on every database operation.

## Authorization & Firestore Security Rules
1. `users/{userId}`: Read by all authenticated users; write ONLY by matching `request.auth.uid`.
2. `events/{eventId}`: Read by public; write ONLY by user with `role == 'organizer'` or `'admin'`.
3. `attendance/{attendanceId}`: Create allowed ONLY if `request.auth != null` AND participant is registered AND attendance window is active.
