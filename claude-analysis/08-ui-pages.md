# Web Application Information Architecture & Pages

## 1. Participant Pages
- **Landing & Schedule**: Hero banner, countdown timer, agenda filters by Day/Track, search bar.
- **Live Virtual Stage & QR Scanner**: Real-time video player, live chat, Q&A upvoting, dynamic QR scanner modal.
- **My Pass & Attendance Log**: Digital QR pass, registered sessions, verified attendance log.

## 2. Organizer & Admin Dashboard
- **Live Attendance Controller**: Select session, trigger attendance window, display dynamic QR code with security token rotation.
- **Real-Time Live Attendance Counter**: Live stream of checked-in participants, attendance percentage gauge.
- **Feedback & Analytics**: Average ratings per session, attendance breakdown, capacity utilization.
